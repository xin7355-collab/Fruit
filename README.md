# 精準務農・精準進貨

蔬果批發行情的手機網頁 App（純前端 PWA，免帳號、可離線）。

- 精準務農：https://xin7355-collab.github.io/Fruit/
- 精準進貨：https://xin7355-collab.github.io/Fruit/merchant/

部署：Settings → Pages → Deploy from a branch：`main`／`/ (root)`。資料由 GitHub Actions 每天自動更新。
需要的 Secrets 與 Variables、測試方法：見 [CLAUDE.md](CLAUDE.md) 第 7 節。
