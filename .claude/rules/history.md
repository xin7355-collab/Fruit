# 版本與分支沿革（從 CLAUDE.md 搬來，內容未刪減）

## 分支慣例

- 開發分支：`claude/vegetable-harvest-weather-system-tjpqnj`
- 資料 JSON 由 `update-data.yml`（天氣，30 分）與 `update-prices.yml`（行情，每日數次）
  兩支排程分別提交到 Pages 所服務的 main 分支根（見 docs/精準務農-詳細說明.md 部署段）。
- 版本號在 `index.html` 的 `const VERSION`（頁尾顯示「精準務農 vX.Y.Z」，淺灰置中）。
  ⚑ 2026-07 應用戶要求「版本從 v1.0.0 開始」，把對外公開版**重置為 `v1.0.0`**（先前 v1.1~v1.10 皆為上架前
  內部迭代，對外不算數；這版＝正式上線第一版）。往後用標準 SemVer `X.Y.Z`：修 bug 進 Z、加功能進 Y、大改版進 X。
  刻意不用日期式版號，以免和右上「更新：<資料時間>」混淆。改前端有感內容時，記得同步把
  `sw.js` 的 `CACHE` 版本號 +1（目前 `jingzhun-farm-v12`）讓舊快取失效。
  **每次改版務必在 `index.html` 的 `CHANGELOG` 陣列最前面新增一筆** {v,date,title,items}，
  會顯示在「設定→關於 App→更新內容」(clModal/renderChangelog，最新標「最新」badge)＝專業版本紀錄。
  目前版本 **v1.0.5**（搭配種法可調：按科別輪作、只用我常種的=慣性施作、每期可鎖定作物）。
  v1.0.4（推薦種植加「一年搭配種法」＝用歷史同期行情逐期挑最賺、輪作排一整年順序與累計淨利）。
  v1.0.3（縮放改原生修正「縮放異常」；推薦種植加「每天淨利」＝淨利÷生育天數、可切每天/整期排序）。
  v1.0.2（採收預判加「當季判斷」標非當季/只推薦當季；推薦種植加肥料/農藥/人工/資材成本→算淨利與保本價）。
  v1.0.1 設定重排＋更新彈窗只顯示本版；v1.0.0 正式上線：19 個批發市場行情看板＋K線、蔬菜/水果採收預判、
  田園巡查(颱風搶收7因子)、全國天氣/颱風、我的品項依類型分類逐品種勾選、資料備份匯出入、純前端 PWA(免帳號/離線/不收個資)。
